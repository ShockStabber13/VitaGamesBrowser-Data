# VitaGamesBrowser Data

Public, downloadable PS Vita game artwork packs and genre metadata for [VitaGamesBrowser](https://github.com/ShockStabber13/VitaGamesBrowser).

Once the IGDB workflow in the private VitaGamesBrowser repository runs successfully, it will publish its catalog data and downloadable ZIP files under `vita/` on this repository's `main` branch.

The repository is for game metadata and cover images only; do not publish NoPayStation package URLs, entitlement data, personal credentials, or secrets.

Some imagery is provided by third-party metadata providers; confirm applicable licensing and redistribution terms before distributing it.
